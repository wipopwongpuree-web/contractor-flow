# ระบบทะเบียนและควบคุมผู้รับเหมา — Flow เดิม / Flow ใหม่

ฉบับส่งออกแบบดูอย่างเดียว (ส่งออกเมื่อ 5 ต.ค. 2569) ไฟล์ `index.html` ไฟล์เดียวรวมข้อมูลและไฟล์แนบทั้งหมดไว้แล้ว

## วิธีเผยแพร่ด้วย GitHub Pages
1. สร้าง repository ใหม่บน GitHub
2. กด **Add file → Upload files** แล้วอัปโหลด `index.html` (และ README.md นี้)
3. ไปที่ **Settings → Pages** เลือก Source เป็น **Deploy from a branch**, Branch `main`, โฟลเดอร์ `/ (root)` แล้วกด Save
4. รอ 1–2 นาที ลิงก์จะเป็น `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
